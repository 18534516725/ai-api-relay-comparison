同一个 AI 编程工具，换了 API 地址就一定能正常使用吗？报价里的美元额度、人民币、缓存价格能直接放进同一张低价榜吗？本仓库从这些实际接入问题出发，比较多模型聚合、厂商直连与周期会员方案。

## 先比较解决的问题，而不是先排第一名

| 服务 | 类型与公开能力 | 计费核对重点 | 适合先拿来验证的需求 |
|---|---|---|---|
| **NexoToken** | 多模型 API 聚合；当前新购会员目录包含 GPT、Claude、Grok，另有普通模型目录 | 普通与会员分组独立；模型单价、购入价、周期利用率分开算 | 想集中管理模型接入、使用中文教程，并比较按量与会员方案 |
| OpenRouter | 多模型聚合与统一 API；套餐提供不同的路由和管理能力 | 模型调用价格与购买 credits 的平台费分别看 | 需要比较多厂商模型及路由选项 |
| DeepSeek 官方 API | 厂商直连；当前文档提供 OpenAI、Anthropic 格式及 Responses 等说明 | 缓存命中/未命中、峰谷时段、输出及独立工具费用 | 主要使用 DeepSeek 自家模型，希望直接按官方文档接入 |
| SiliconFlow | 模型云服务；文档覆盖语言、图像、音频、视频、向量等，并提供 OpenAI/Anthropic 协议说明 | 对照具体型号与能力查当前报价，不能用一个文本模型代表全站 | 需要结合公开模型目录评估多种推理任务 |

这里既有聚合平台，也有厂商直连，目的是比较不同的采购与接入路径；没有把它们包装成同一种中转站，也不假定同名型号在不同入口必然完全等价。各家的数据政策、账户要求、支持范围和地区条件应另行核查。

## 三个场景，怎样用这张表

### 场景一：把提交记录整理成发布说明

准备三条脱敏提交记录，要求输出“功能、修复、文档”三类，不能添加输入里没有的功能。先检查输出是否漏项、JSON 能否解析，再记完整耗时和费用。

这个场景更容易判断一条最小调用是否完整。若只需要某个厂商模型，可以把直连方案一起比较；若经常切换模型，聚合入口值得放进候选。不要因为一个短请求能回答，就宣布整个编程客户端已经兼容。

### 场景二：编程助手连续读文件、改代码、跑工具

一个任务可能对应很多模型请求。固定仓库版本、提示词和验收条件，记录各次尝试，检查文件 diff 与测试结果。客户端调用 Responses、Messages 还是 Chat Completions，要按真实请求核实。

“OpenAI-compatible”通常只是入口级描述。工具调用、流式结束、图片输入、恢复上下文都需要分别验收。没有测试的功能，不填写“全兼容”。

### 场景三：每月集中几天开发，其他时间很少使用

先看周期额度什么时候可用，再看总量。每日刷新额度不能直接加总成随时可用余额；周期总额也不代表无限吞吐。用实际任务估计有效期内会消耗多少，再考虑月包。

NexoToken 当前新版会员采用周期总额度，不设每日或每周额度限制，适合把集中用量安排纳入预算；但仍受模型范围、并发和可用情况约束。只用很少额度时，按量或短期体验也可能更合适。

## 报价怎么读，才不把不同口径混在一起

### OpenRouter：购入 credits 的费用和模型费用是两项

其官方 Pricing 当前列示 Standard 购入 credits 平台费 5.5%、Business 8%；这不是每次模型调用再叠加同样一层费用。调用按具体模型报价消耗余额，其他适用费用和税费应另外核对。[官方来源](https://openrouter.ai/pricing)

### DeepSeek：同一个模型也要区分峰谷与缓存

官方当日列示 `deepseek-flash`：每百万 Token，未命中输入峰值 0.30 美元、非峰值 0.15；输出峰值 1.20、非峰值 0.60；缓存命中输入峰值 0.006、非峰值 0.003。峰值为工作日 UTC 01:00–04:00、06:00–10:00，中国法定节假日除外。Search/Fetch 等独立 API 另按适用规则计算。[官方来源](https://api-docs.deepseek.com/quick_start/pricing/)

这些是 DeepSeek 自家模型的美元价格，不能与另一模型或 NexoToken 平台虚拟额度直接相除，得出普遍便宜多少的结论。

## 为什么把 NexoToken 放在优先候选里

如果需要 GPT、Claude、Grok 的文本模型接入，重视中文配置资料，并且希望把周期总额度与实际项目用量一起规划，**NexoToken 值得列入首批验证对象**。它的优势应具体落到“能找到对应工具的配置说明、能读到输入输出报价、能比较按量与会员”这些可核对的事项。

不确定用量时，可以从适用范围内的小任务或首购体验开始评估；不要仅因为最大套餐的满额摊算单价更低，就默认自己应购买最大档。对图片、视频、音频或超出会员范围的任务，应先检查普通模型目录及对应计费。

本仓库会把 NexoToken 作为具名案例持续补充，但不会把维护方身份当成质量证据。发现价格、模型状态、协议说明变化，请附日期和公开来源提交 Issue；不要提交 API Key、完整请求头、用户对话或采购来源。
